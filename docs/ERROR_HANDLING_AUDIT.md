# 老师端全链路错误处理梳理

适用范围：Vercel 老师工作台，2026-10-26。

## 提示原则

每次失败都说明发生了什么、下一步操作以及需要保留的内容。页面不展示数据库、模型协议、解析器或 JavaScript 的原始报错。参考编号供管理员查日志，不要求老师理解。

只有能确定具体字段不合规时，才要求老师修改填写内容。AI 少生成课次、章节检查失败、网络中断、服务繁忙都不应被解释为老师的提示词写得不好。

## 环节与处理

| 环节 | 识别的问题 | 老师看到的下一步 |
| --- | --- | --- |
| 登录 | 密码不正确、账号停用、网络故障、操作频繁分别识别 | 重新输入、联系管理员启用、检查网络或等待 1 分钟 |
| 修改密码、退出 | 请求失败不应一直停在处理中 | 保留页面，稍后重试；不把网络失败当成密码错误 |
| 教师资料 | 资料读取失败不再一直显示加载中 | 重新读取资料；资料恢复前不交付缺少介绍的报告 |
| 本地草稿 | 存储不可用时不应仍声称草稿已保存 | 保留页面，复制课堂记录备份 |
| 填写检查 | 缺少姓名、成绩范围错误、课次不匹配、数学领域分配或语言成绩错误 | 指出相应字段并定位，给出允许范围或填写示例 |
| 文件选择 | 格式不支持、空文件、超过 8MB | 重新选择支持格式的非空文件，或压缩、精简文件 |
| 文件提取 | 扫描 PDF 无文字、损坏或加密文件、超过 5 万字 | 改传可复制文字的 PDF、Word 或 Excel，另存为或仅保留本次规划 |
| 文件 AI 解析 | 服务未完成解析 | 重新解析；仍失败时另存为 Word 或 Excel 后上传，反馈无需重填 |
| 复用检查 | 历史结果查询或读取暂时失败 | 保留填写内容，继续生成；登录和权限错误仍停止 |
| AI 生成 | 网络、超时、繁忙与生成结果不合格分别识别 | 网络恢复后继续；繁忙等 1 分钟；结果不合格继续生成，无需随意改写课堂记录 |
| 分阶段进度 | 已完成内容不应因一次失败全部重做 | 显示已保留的阶段数量，继续时使用可用进度 |
| 报告展示 | 结果已生成但展示失败 | 先保存报告，再重试预览或从历史报告打开，不重复生成 |
| 自动、手动保存 | 保存失败不能伪装成生成失败 | 保留本页，重新保存；检查指定的阶段、课次、时长或过长内容 |
| 登录过期 | 刷新可能丢掉当前表单或文件 | 在新窗口登录，回到原页面重试 |
| 历史列表、打开 | 连接失败与报告不存在分开 | 重试读取或打开；不存在时刷新列表、确认账号并联系管理员 |
| PDF 导出 | 图片损坏、加载停滞、打印窗口未打开 | 图片最多等待 15 秒；恢复网络后重试，必要时保存后重新打开，不重新生成 |
| 复制话术 | 浏览器禁止剪贴板 | 手动选中文字后复制 |

## 保存重试

保存请求不自动重发。新报告使用稳定的保存标识；若服务端已保存但响应丢失，手动重试更新同一份属于当前老师的记录，避免重复新增。无需数据库迁移。

## 诊断边界

浏览器诊断仅记录环节、接口、错误类型、尝试次数、状态和参考编号。服务端分阶段生成、文件解析、报告存储的失败也提供参考编号。诊断不包含学生姓名、课堂记录、文件正文、密码或模型完整输入输出。

## 验证

自动化覆盖错误分类、字段定位、登录过期、保存失败、文件替换指引、图片等待上限、保存标识格式与隐私边界。浏览器流程覆盖复用失败后继续、生成网络失败、保存失败后重试以及导出图片失败。浏览器测试使用模拟接口，不修改真实老师数据。

普通可恢复故障优先提供直接操作按钮，不在第一步要求联系管理员。显示失败支持重新加载现有报告，不重新调用 AI；只有权限、服务配置等老师无法处理的问题直接建议管理员介入。问题编号折叠展示，供多次自助尝试仍失败时使用。

自动化回归包含填写错误定位、登录过期保留表单、样式预览失败重试，以及显示异常后不重新生成即可恢复报告。

本轮验证：248 项自动化测试、16 条浏览器流程和生产构建全部通过。
